## 3. Keep

- Before writing to an external route, read the target repository's generated contract (here, a sibling skmtc-hub worktree). The rule belongs in the `orbital-ticket-prep` skill and the author prompt's self-review questions.
- Run subprocess tests under the install's exact permissions (`--allow-run=deno,sh`). That proves git really goes through `sh`, which `--allow-all` hides. Already shown in `deno/cli/lib/env-entry.test.ts`; worth naming in `deno/cli/CLAUDE.md`.
- Test command injection with a stand-in opener on PATH that records `$#` and its arguments. Reuse it for any future `sh` spawn.

## 4. Deferred

- `deno/cli/lib/linked-repo-detect.ts` `findPublishWorkflows`: scans cwd, not the git root. A user running from a monorepo subfolder (e.g. `deno/`) gets "no workflow" ([PR comment](https://github.com/skmtc/skmtc/pull/263#issuecomment-6529303543)).
- `deno/cli/lib/api-link-headless.ts` `toFailureMessage`: a fixed "not an admin" text for every 403. An admin whose PAT lacks `publish:schemas`, or a refused org owner, is misled (same comment).
- `deno/cli/lib/api-link-headless.ts`: a fixed 429 text ignores the hub's message and Retry-After. A user is told to wait 15 min when the earliest request expires sooner (same comment).
- `deno/docs/reference/cli/login.md:19-21` and the `deno/cli/commands/login.tsx` header still say the deno,sh install cannot open a browser, which is now stale. A reader of the login docs meets it (same comment).
- `parseGithubRemote`: rejects `https://user@github.com/...`, ssh with a port, and host aliases; when git is missing (sh exits 127), the message says "no git remote". A developer with such a remote must pass `--repo` (author self-review).
- Workflow markers: a workflow running `deno run jsr:@skmtc/cli api publish` is missed, and a commented `skmtc api publish` counts. Users of the deno-run form hit exit 2 (author self-review; the ticket fixed the markers).
- `isCi`: only the value `true` counts, so a CI that sets `CI=1` still runs the opener (author self-review).
- `--environment` output echoes the raw value; the hub lowercases it, so an agent comparing the CLI output with the page sees a mismatch (author self-review).
- Not verified: a real request to skmtc-hub and a real browser opening. This needs a login or PAT against a live hub (author and follow_on).
