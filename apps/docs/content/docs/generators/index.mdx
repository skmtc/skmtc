## Frequently Asked Questions

### How do I update generators?

```bash
# Update all generators
skmtc update

# Update specific generator
skmtc update @skmtc/gen-typescript

# Check for updates
skmtc outdated
```

### Can I use multiple versions?

Yes, use aliases in your config:

```json
{
  "generators": [
    { "name": "@skmtc/gen-typescript", "version": "1.0.0", "alias": "ts-v1" },
    { "name": "@skmtc/gen-typescript", "version": "2.0.0", "alias": "ts-v2" }
  ]
}
```

### How do I remove a generator?

```bash
skmtc uninstall @skmtc/gen-typescript
```
