This comprehensive guide walks you through your first code generation with Skmtc, from setup to integration.

## What we'll build

We'll generate a complete TypeScript API client from an OpenAPI specification, including:
- Type-safe interfaces
- API client with fetch
- Zod validation schemas
- React Query hooks

## Prerequisites

- Skmtc installed ([installation guide](/docs/getting-started/installation))
- A TypeScript project (we'll create one if needed)
- Basic familiarity with TypeScript and React

<Steps>

<Step>

### Create a new project

If you don't have a project yet, let's create one:

```bash
# Create a new Next.js app (or use your existing project)
npx create-next-app@latest my-api-client --typescript --tailwind --app
cd my-api-client
```

</Step>

<Step>

### Initialize Skmtc

Run the interactive initialization:

```bash
skmtc init
```

You'll be prompted with several questions:

```
? Where would you like to generate code? ./src/generated
? Which generators would you like to use? (Space to select)
  ◉ TypeScript Types
  ◉ Tanstack Query + Fetch
  ◯ Zod Schemas
  ◯ MSW Mocks
? What naming convention for files? kebab-case
? Enable watch mode by default? Yes
? Format with Prettier? Yes
```

This creates a `.skmtc` configuration folder:

<Step>

### Install generators

Install the generators you selected:

```bash
# Install TypeScript and Tanstack Query generators
skmtc install @skmtc/gen-typescript
skmtc install @skmtc/gen-tanstack-query-fetch-zod
```

<Callout type="info">
Generators can have dependencies. Installing `tanstack-query-fetch-zod` automatically includes TypeScript types and Zod schemas.
</Callout>

</Step>

<Step>

### Prepare your OpenAPI spec

You can use:
1. **A remote URL** (we'll use the Petstore example)
2. **A local file** (your own `openapi.json`)
3. **Auto-discovery** from your backend

For this guide, we'll use the Petstore API:

```bash
# Preview the spec structure
curl https://petstore3.swagger.io/api/v3/openapi.json | head -20
```

</Step>

<Step>

### Generate the code

Run the generation command:

```bash
skmtc generate https://petstore3.swagger.io/api/v3/openapi.json

### Examine the generated types

Open `src/generated/types/pet.ts`:

/**
 * Pet
 * A pet in the store
 */
export interface Pet {
  id?: number;
  name: string;
  category?: Category;
  photoUrls: string[];
  tags?: Tag[];
  status?: 'available' | 'pending' | 'sold';
}

export type CreatePetRequest = Omit<Pet, 'id'>;
export type UpdatePetRequest = Pet;
```

</Step>

<Step>

### Review the API hooks

Check `src/generated/hooks/use-get-pet.ts`:

```typescript
import { useQuery } from '@tanstack/react-query';
import { z } from 'zod';
import { Pet } from '../types';
import { PetSchema } from '../schemas';
import { apiClient } from '../client';

export interface UseGetPetParams {
  petId: number;
}

export function useGetPet(
  params: UseGetPetParams,
  options?: UseQueryOptions<Pet>
) {
  return useQuery({
    queryKey: ['pet', params.petId],
    queryFn: async () => {
      const response = await apiClient.get(`/pet/${params.petId}`);

      // Runtime validation with Zod
      return PetSchema.parse(response.data);
    },
    ...options,
  });
}
```

</Step>

<Step>

### Set up the providers

Configure React Query in your app:

```tsx
// app/providers.tsx
'use client';

import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import { useState } from 'react';

export function Providers({ children }: { children: React.ReactNode }) {
  const [queryClient] = useState(
    () => new QueryClient({
      defaultOptions: {
        queries: {
          staleTime: 60 * 1000, // 1 minute
          refetchOnWindowFocus: false,
        },
      },
    })
  );

  return (
    <QueryClientProvider client={queryClient}>
      {children}
      <ReactQueryDevtools />
    </QueryClientProvider>
  );
}
```

</Step>

<Step>

### Use the generated code

Create a component using the generated hooks:

```tsx
// app/components/pet-details.tsx
'use client';

import { useGetPet } from '@/generated/hooks';
import { Pet } from '@/generated/types';

export function PetDetails({ petId }: { petId: number }) {
  const { data: pet, isLoading, error } = useGetPet({ petId });

  if (isLoading) return <div>Loading pet...</div>;
  if (error) return <div>Error loading pet</div>;
  if (!pet) return <div>Pet not found</div>;

  return (
    <div className="p-4 border rounded">
      <h2 className="text-2xl font-bold">{pet.name}</h2>
      {pet.category && (
        <p className="text-gray-600">Category: {pet.category.name}</p>
      )}
      <p className="mt-2">Status: {pet.status}</p>

      {pet.photoUrls.length > 0 && (
        <div className="mt-4">
          <h3 className="font-semibold">Photos:</h3>
          <div className="grid grid-cols-3 gap-2 mt-2">
            {pet.photoUrls.map((url, i) => (
              <img
                key={i}
                src={url}
                alt={`${pet.name} photo ${i + 1}`}
                className="w-full h-32 object-cover rounded"
              />
            ))}
          </div>
        </div>
      )}
    </div>
  );
}
```

</Step>

<Step>

### Create mutations

Use generated mutation hooks for creating/updating:

```tsx
// app/components/create-pet-form.tsx
'use client';

import { useCreatePet } from '@/generated/hooks';
import { CreatePetRequest } from '@/generated/types';
import { useState } from 'react';

export function CreatePetForm() {
  const [name, setName] = useState('');
  const createPet = useCreatePet();

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();

    const newPet: CreatePetRequest = {
      name,
      photoUrls: [],
      status: 'available',
    };

    createPet.mutate(newPet, {
      onSuccess: (pet) => {
        console.log('Created pet:', pet);
        setName('');
      },
      onError: (error) => {
        console.error('Failed to create pet:', error);
      },
    });
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Pet name"
        className="px-4 py-2 border rounded"
        required
      />

      <button
        type="submit"
        disabled={createPet.isPending}
        className="px-4 py-2 bg-blue-500 text-white rounded"
      >
        {createPet.isPending ? 'Creating...' : 'Create Pet'}
      </button>
    </form>
  );
}
```

</Step>

## Understanding the output

### Type safety everywhere

The generated code provides end-to-end type safety:

```typescript
// ✅ Type-safe parameters
const { data } = useGetPet({ petId: 123 });

// ❌ TypeScript error - wrong type
const { data } = useGetPet({ petId: "123" });

// ✅ Autocomplete for response data
if (data) {
  console.log(data.name); // TypeScript knows this is a string
  console.log(data.status); // Knows this is 'available' | 'pending' | 'sold'
}
```

### Runtime validation

Zod schemas validate API responses at runtime:

```typescript
// The generated schema ensures data integrity
const PetSchema = z.object({
  id: z.number().optional(),
  name: z.string(),
  status: z.enum(['available', 'pending', 'sold']).optional(),
  // ... other fields
});

// Automatically validated in hooks
const response = await fetch('/api/pet/1');
const pet = PetSchema.parse(await response.json()); // Throws if invalid
```

### Regeneration workflow

When your API changes:

1. Update your OpenAPI spec
2. Run `skmtc generate` again
3. TypeScript will show any breaking changes
4. Fix the type errors in your code

## Configuration tips

### Customize the output

Edit `.skmtc/config.json`:

```json
{
  "output": "./src/api",
  "generators": {
    "typescript": {
      "enumStyle": "union", // or "enum"
      "dateType": "Date", // or "string"
    },
    "tanstack-query": {
      "version": 5,
      "clientName": "apiClient",
      "baseUrl": "https://api.example.com"
    }
  }
}
```

### Watch mode

Enable automatic regeneration when your spec changes:

```bash
skmtc watch ./openapi.json
```

### CI/CD integration

Add to your build pipeline:

```yaml
# .github/workflows/generate.yml
- name: Generate API client
  run: |
    npx skmtc generate ${{ secrets.API_SPEC_URL }}
    git diff --exit-code || (
      echo "Generated code is out of date"
      exit 1
    )
```

## Common patterns

### Error handling

```typescript
const { data, error } = useGetPet(
  { petId },
  {
    retry: 3,
    onError: (error) => {
      if (error.response?.status === 404) {
        toast.error('Pet not found');
      } else {
        toast.error('Failed to load pet');
      }
    },
  }
);
```

### Optimistic updates

```typescript
const queryClient = useQueryClient();
const updatePet = useUpdatePet();

updatePet.mutate(updatedPet, {
  optimisticUpdate: async (newPet) => {
    await queryClient.cancelQueries(['pet', newPet.id]);
    const previous = queryClient.getQueryData(['pet', newPet.id]);
    queryClient.setQueryData(['pet', newPet.id], newPet);
    return { previous };
  },
  onError: (err, newPet, context) => {
    queryClient.setQueryData(['pet', newPet.id], context.previous);
  },
});
```

## Troubleshooting

<Callout type="warning">
**Common issues:**

- **"Cannot find module"** - Run `npm install @tanstack/react-query zod`
- **CORS errors** - Configure your API server or use a proxy
- **Type mismatches** - Regenerate after API changes
- **Build errors** - Ensure TypeScript is configured for your output directory
</Callout>
