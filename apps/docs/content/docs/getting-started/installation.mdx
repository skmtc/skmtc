## System requirements

Before installing Skmtc, ensure you have:

- **Node.js** 18.0+ or **Deno** 2.5+
- **npm** 7.0+ (or yarn/pnpm)
- **Git** (for version control)
- 50MB of disk space

## Installation methods

### Global installation (recommended)

Install Skmtc globally to use it from any directory:

<Tabs items={['npm', 'yarn', 'pnpm', 'bun', 'deno']}>
<Tab value="npm">
```bash
npm install -g @skmtc/cli
```
</Tab>
<Tab value="yarn">
```bash
yarn global add @skmtc/cli
```
</Tab>
<Tab value="pnpm">
```bash
pnpm add -g @skmtc/cli
```
</Tab>
<Tab value="bun">
```bash
bun add -g @skmtc/cli
```
</Tab>
<Tab value="deno">
```bash
deno install -A -g jsr:@skmtc/cli
```
</Tab>
</Tabs>

Verify the installation:

```bash
skmtc --version
```

### Project-specific installation

Install Skmtc as a dev dependency in your project:

<Tabs items={['npm', 'yarn', 'pnpm', 'bun']}>
<Tab value="npm">
```bash
npm install --save-dev @skmtc/cli
```
</Tab>
<Tab value="yarn">
```bash
yarn add --dev @skmtc/cli
```
</Tab>
<Tab value="pnpm">
```bash
pnpm add -D @skmtc/cli
```
</Tab>
<Tab value="bun">
```bash
bun add -d @skmtc/cli
```
</Tab>
</Tabs>

Add to your `package.json` scripts:

```json
{
  "scripts": {
    "generate": "skmtc generate",
    "skmtc:init": "skmtc init",
    "skmtc:install": "skmtc install"
  }
}
```

### Using npx (no installation)

Run Skmtc without installing:

```bash
npx @skmtc/cli generate https://api.example.com/openapi.json
```

<Callout type="info">
Using npx is convenient for trying Skmtc but slower for repeated use. We recommend global installation for regular development.
</Callout>

## Monorepo setup

Skmtc works seamlessly with monorepo tools:

### Turborepo

Add to your root `turbo.json`:

```json
{
  "pipeline": {
    "generate": {
      "cache": false,
      "outputs": ["generated/**"]
    }
  }
}
```

### Nx

Add to `workspace.json`:

```json
{
  "projects": {
    "my-app": {
      "targets": {
        "generate": {
          "executor": "nx:run-commands",
          "options": {
            "command": "skmtc generate"
          }
        }
      }
    }
  }
}
```

### Lerna

Add to package scripts:

```json
{
  "scripts": {
    "generate": "lerna run generate --stream"
  }
}
```

## Docker installation

Use Skmtc in Docker environments:

```dockerfile
FROM node:20-alpine

# Install Skmtc globally
RUN npm install -g @skmtc/cli

# Copy your OpenAPI spec
COPY openapi.json .

# Generate code during build
RUN skmtc generate openapi.json --output /generated

# Or use as a development container
WORKDIR /app
CMD ["skmtc", "watch"]
```

## IDE and editor setup

### VS Code

Install recommended extensions for the best experience:

```json
// .vscode/extensions.json
{
  "recommendations": [
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "streetsidesoftware.code-spell-checker"
  ]
}
```

Add workspace settings:

```json
// .vscode/settings.json
{
  "files.exclude": {
    "**/.skmtc/cache": true
  },
  "search.exclude": {
    "**/generated": true
  }
}
```

### JetBrains IDEs

Mark generated folders as excluded:
1. Right-click the `generated` folder
2. Select "Mark Directory as" → "Excluded"

## Environment variables

Skmtc supports these environment variables:

```bash
# Set output directory
export SKMTC_OUTPUT=./src/generated

# Disable telemetry
export SKMTC_DISABLE_TELEMETRY=true

# Set log level (debug, info, warn, error)
export SKMTC_LOG_LEVEL=debug

# Custom config location
export SKMTC_CONFIG=./custom-skmtc.json
```

## Verification

After installation, verify everything works:

```bash
# Check version
skmtc --version

# View available commands
skmtc --help

# Initialize a test project
mkdir skmtc-test && cd skmtc-test
skmtc init

# Generate from example API
skmtc generate https://petstore3.swagger.io/api/v3/openapi.json
```

## Troubleshooting installation

### Permission errors (npm/yarn)

If you get EACCES errors:

```bash
# Option 1: Use a Node version manager (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install node
npm install -g @skmtc/cli

# Option 2: Change npm's default directory
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### Command not found

After global installation, if `skmtc` is not found:

1. Check your PATH includes npm's global bin:
   ```bash
   npm config get prefix
   # Add the bin directory to your PATH
   ```

2. For yarn global installs:
   ```bash
   yarn global bin
   # Add this directory to your PATH
   ```

### Proxy configuration

Behind a corporate proxy:

```bash
npm config set proxy http://proxy.company.com:8080
npm config set https-proxy http://proxy.company.com:8080
npm install -g @skmtc/cli
```

### Version conflicts

If you have multiple Node versions:

```bash
# Use nvm to manage versions
nvm use 20
npm install -g @skmtc/cli

# Or use npx with specific Node
npx -p node@20 @skmtc/cli generate
```
