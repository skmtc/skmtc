Get up and running with Skmtc in just 5 minutes. This guide will walk you through generating TypeScript types from an OpenAPI specification.

## What you'll learn

In this quick start, you'll:
- Install Skmtc
- Generate TypeScript types from an OpenAPI spec
- Understand the generated output
- Integrate the code into your project

## Prerequisites

- Node.js 18+ or Deno 2.5+
- Basic familiarity with OpenAPI/Swagger
- A TypeScript project (optional, we'll show you how to create one)

<Steps>

<Step>

### Install Skmtc

<Tabs items={['npm', 'yarn', 'pnpm', 'deno']}>
<Tab value="npm">
```bash
npm install -g @skmtc/cli
# Or use directly with npx
npx skmtc
```
</Tab>
<Tab value="yarn">
```bash
yarn global add @skmtc/cli
```
</Tab>
<Tab value="pnpm">
```bash
pnpm add -g @skmtc/cli
```
</Tab>
<Tab value="deno">
```bash
deno install -A -g jsr:@skmtc/cli
```
</Tab>
</Tabs>

</Step>

<Step>

### Initialize your project

Run the interactive setup to configure Skmtc for your project:

```bash
skmtc init
```

This creates a `.skmtc` folder with your configuration. When prompted:
- Choose "TypeScript" as your first generator
- Select your output directory (default: `./generated`)
- Choose your formatting preferences

</Step>

<Step>

### Add a TypeScript generator

Install the TypeScript generator to create type definitions:

```bash
skmtc install @skmtc/gen-typescript
```

</Step>

<Step>

### Generate your code

Now generate TypeScript types from an OpenAPI specification:

```bash
# Using a remote URL (try this example!)
skmtc generate https://petstore3.swagger.io/api/v3/openapi.json

# Or use a local file
skmtc generate ./openapi.json
```

</Step>

<Step>

### Explore the output

Check your `generated` folder (or your configured output directory):

```typescript
// generated/types/Pet.ts
export interface Pet {
  id?: number;
  name: string;
  category?: Category;
  photoUrls: string[];
  tags?: Tag[];
  status?: 'available' | 'pending' | 'sold';
}

// generated/types/Category.ts
export interface Category {
  id?: number;
  name?: string;
}
```

</Step>

</Steps>

## What just happened?

Skmtc processed your OpenAPI specification through three phases:

1. **Parse**: Validated and analyzed your OpenAPI document
2. **Generate**: Transformed schemas into TypeScript definitions
3. **Render**: Formatted and wrote the files with proper styling

The generated types are:
- ✅ **Type-safe** - Full TypeScript support with proper optionals
- ✅ **Clean** - Formatted with Prettier, following your conventions
- ✅ **Modular** - Each type in its own file for better organization
- ✅ **Ready to use** - Import directly into your TypeScript code

## Using the generated types

Import and use the types in your application:

```typescript
import { Pet } from './generated/types/Pet';
import { Category } from './generated/types/Category';

// Type-safe API response handling
async function fetchPet(id: number): Promise<Pet> {
  const response = await fetch(`/api/pets/${id}`);
  return response.json() as Pet;
}

// Type-safe data creation
const newPet: Pet = {
  name: 'Fluffy',
  photoUrls: ['https://example.com/fluffy.jpg'],
  status: 'available'
};
```

## Common questions

### Can I regenerate when my API changes?
Yes! Run `skmtc generate` again anytime. Skmtc will cleanly regenerate all files.

### Does this work with existing projects?
Absolutely. Skmtc generates standalone code that integrates with any TypeScript project.

### Can I customize the output?
Yes, through configuration and custom generators. See our [configuration guide](/docs/using-generators/configuration).
