**Skmtc** is a declarative code generation framework for TypeScript. It is Open Source and licensed under Apache v2 license.

## Features

- Works natively with OpenAPI 3.0. Swagger 2.0 and OpenAPI 3.1 get converted to 3.0
- Generates UI elements, as well as clients and servers
- Modular architecture allows generator stacking and reuse
- Generator output specified plain string templates for easy customization
- Full control over output naming and file structure
- Choose from 11 generators or create your own

## Quick Start

Run Skmtc code generation using npx

```bash
npx skmtc generate @skmtc/supabase-backend
```


## Installation

You can install Skmtc as a global dependency to run it without `npx` command

```bash
npm install skmtc -g
```

## Usage

Run Skmtc code generation using `generate` command followed by project name and url/path to OpenAPI schema.

```bash
npx skmtc generate @skmtc/supabase-backend https://petstore3.swagger.io/api/v3/openapi.json
# Outputs generated files in current folder
```
