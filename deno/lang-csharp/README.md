# @skmtc/lang-csharp

SKMTC language package for **C#** — the third production language on
the frozen seam (TypeScript, Kotlin, C#).

Renders: `.cs`

**Status: production (CS-A).** Ships the naming layer (`record` /
`enum` kinds with spelled-out factories, the `@` verbatim-identifier
escape, export-path → namespace derivation, enum member naming with
full-produced-set dedup), the DSL classes (`CsFile` with the
compiler-mandated `// <auto-generated/>` + `#nullable enable` header
pair, `CsImport` with symbol-level registration and namespace-level
`using` rendering, `CsDefinition` shells, `CsPropertyList`,
`CsAttribute`), the value protocols (`CsAttributed`, `CsDocumented`,
`CsBased` — declared now, rendered at CS-B), and the write path (the
`csharp` Lang object, `CsSnippet`, the register functions, the
`toModelProjectionBase` veneer).

Rendering lives on each object's own `toString()` — there is no
central renderer object, and `@skmtc/core` never imports from here.
Grammar/policy boundary: `System.Text.Json` is never named in this
package's production code — the lang renders any attribute it is
handed; serialization flavor belongs to `@skmtc/gen-csharp` (the
Newtonsoft-sibling clone seam).

Proving generator: `@skmtc/gen-csharp` (fleet). Arc spec (single
document): [`../../notes/lang/31-csharp-kickoff.md`](../../notes/lang/31-csharp-kickoff.md).
Operational answers: the `skmtc-lang-csharp` skill
([`../docs/skills/skmtc-lang-csharp/SKILL.md`](../docs/skills/skmtc-lang-csharp/SKILL.md)).

Milestone arc: CS-A (DTOs — this release) → CS-B (abstract-record
polymorphic `oneOf`) → CS-C (ASP.NET controllers + service seam) →
CS-D (polish parity). Validated floor = validation toolchain =
**.NET 10 LTS**.
