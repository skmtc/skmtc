# Friction log reviews

Periodic review files produced by the `skmtc-retro-review` skill. Each
file covers a review period (monthly, quarterly, or pre-release) and
contains:

- Convergence metrics (Friction Recurrence Rate, Blocker%, open entry
  count, knowledge backlog)
- Clustered friction patterns with root cause hypotheses
- Prioritized action plan with specific, falsifiable success criteria
- Follow-up on prior period recommendations
- Cumulative metrics history table (one row per review, never truncated)

Files are named `<YYYY-MM-DD>-review-<period>.md`. The date is when the
review was run; the period describes what was reviewed.

See [skmtc-retro-review skill](../../skills/skmtc-retro-review/SKILL.md)
for how reviews are produced.
